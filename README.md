# Babunty Devi Sahani Foundation

Official website for **Babunty Devi Sahani Foundation** (BDS Foundation).

- **Domain:** [babuntydevisahani.org](https://babuntydevisahani.org)
- **Email:** contact@babuntydevisahani.org

## Overview

A dedicated non-profit philanthropic foundation committed to grassroots social empowerment across 4 core pillars:
1. **Education & Youth Literacy**
2. **Healthcare & Wellness Outreach**
3. **Women Empowerment & Vocational Skills**
4. **Grassroots Rural & Community Care**

## Tech Stack

- Semantic HTML5 & Modern Vanilla CSS
- Responsive design with glassmorphism aesthetics
- Lightweight Vanilla JavaScript
- CNAME configuration for `babuntydevisahani.org`

## Deployment & Hosting

This repository is ready to be served via GitHub Pages, Netlify, Vercel, or any static web server:
- Custom domain `babuntydevisahani.org` is configured via `CNAME`.
- If using GitHub Pages, enable it from **Repository Settings > Pages > Source (Deploy from a branch: `main` / root)**.
